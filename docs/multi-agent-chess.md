# Multi-agent chess

Every piece is an agent: sixteen a side. Each turn the agents of the side to
move agree on a plan, the best move their shared engine finds. Some agents go
their own way. The question is what keeps a team on its plan, and whether a
Modality contract does it better than agents writing rules for themselves.

To watch games step by step, see the [experiment page](https://www.modality.org/experiments/multi-agent-chess).
The code is [`examples/multi-agent-chess`](https://github.com/modality-org/modality/tree/main/examples/multi-agent-chess).
These results come from 512 games played at the example as committed with this page. In the
352 games where Black plays through a contract, every Black move
is a commit that `modal` checked, and in 352 of them the contract's own
log agrees with the moves the referee played and the pieces that made them.
In 304 games, agents wrote rules with a language model.

## The setup

**The agents.** Both sides use the same engine and the same fault rates. At
the default rate of 0.1:

| Fault | What the agent does |
| --- | --- |
| Panic | A threatened piece runs, whatever the plan says |
| Greed | A piece grabs a capture, whatever the plan says |
| Amnesia | The piece the team chose forgets the plan and moves somewhere else |
| Rogue | One compromised agent plays its worst move every turn, from ply 10 |

**A piece can only move itself.** An agent can talk about any move, but the
only move it can send is one of its own piece's. Each side holds this rule in
its own way.

**White** coordinates over chat. Each White agent can send its own move to
the referee, and the referee plays the first move it receives from the piece
that makes it.

- *With RULES.md*, White also keeps a shared file that any White agent can
  edit. Nothing checks it. When an off-plan move is played, the team holds a
  retro and one agent adds a rule. An agent about to go off plan follows a
  rule that covers what it is about to do half the time (or always, in one
  experiment). A rogue empties the file whenever it finds rules in it.

**Black** coordinates through a Modality contract. A move is the
`/moves/<agent>.text` of an accepted commit, and the referee plays the first
Black move the contract accepts and reads nothing else. The rule
`always([+modifies(/moves/$k.text) -signed_by(/team/pieces/$k.id)] false)`,
where `$k` stands for every agent, says only a piece can write its own move,
so a piece can only formally propose its own movement. An agent that goes off plan signs its own commit alone; the
team's plan is signed by the piece that moves and every agent that agrees
with it.

- *Over chat*, in one experiment, Black coordinates the way White does, so
  neither side has a contract or shared rules.
- *With the preset contract*, two more rules hold from the first commit: a
  commit needs four of the sixteen Black agents' signatures, and the roster
  of agents can never change.
- *Self-ruled*, the contract starts with the roster and the per-piece rule
  only. Any piece can still move itself alone, so Black plays like White
  until its agents write rules. When
  an off-plan move is played, one agent writes a rule in plain language,
  `modal contract ai suggest-rule` turns it into a formula, and the team
  commits it with a witness model. `modal` refuses a rule commit that breaks
  the rules already there, and no rule can be removed.

**Retros.** Each side holds at most three retros a game. Both sides' agents
are asked by the same language model with the same description of what
happened; only the part about how their team coordinates differs. The
model is Claude Sonnet 5.5, pinned, reached through the Claude Code CLI and,
for formulas, `modal ai`'s `claude-cli` provider. Every answer is cached with
its model, so a rerun of these games asks nothing new.

**Pawns with personalities.** Each pawn draws its own panic, greed and
amnesia rates (0 to 2 times the base rate) and its own compliance with
RULES.md (0 to 1). The averages match the other agents'. The pawns on a file
share a personality on both sides.

**When no move lands.** On chat, some move always reaches the referee. On a
contract, every move sent can be refused. Then the team asks again; if the
piece it chose goes off plan twice, the team plans around that piece. A side
whose own agreed plan is refused three times on one ply forfeits: its rules
leave the team no way to move. White never gets a second try, and Black's
second tries cost it moves a little worse than its first plan, which the
results count.

An agent about to go off plan that follows a RULES.md rule sends the plan
instead, or nothing if it was not the piece chosen.

## What the experiments show

**Over chat, both teams drift alike.** With both sides on chat, White's agents sent 10.6 off-plan moves a game and the referee played 8.1; Black's sent 10.4 and 8.2 were played. Black scored 0.41, against 0.44 when no agent goes off plan.

**A contract holds a team to its plan; chat does not.** In the baseline, White's agents sent 8.4 off-plan moves a game and the referee played 6.4 of them. Black's agents sent 12.8, and the contract refused every one. Black scored 0.91, against 0.44 with no faults at all.

**Written rules help as far as agents obey them.** White's agents wrote good rules, nearly all of the form "send only the agreed move". Followed half the time, they cut the off-plan moves White played from 6.4 to 3.8 a game, and Black's score fell from 0.91 to 0.75. Followed always, White played 1.0 a game: 31 off-plan moves before its first rule and 0 after. Black scored 0.56, against 0.44 with no faults. A RULES.md that every agent always obeys nearly does what the contract does. The contract does not need anyone to obey it.

**Left to write their own contract, Black's agents wrote the preset contract's kind of rule.** Of the 146 rules `modal` accepted from Black's agents, 134 require a number of the sixteen agents' signatures: 54 at 14 of 16, 51 at 12 of 16, 17 at 13 of 16, 10 at 15 of 16, 2 at 16 of 16; 12 say something else. Outside the rogue experiment, Black's first rule went in at its first retro in 45 of the 47 games that held one, after one costly move, and in 48 games Black played 0 off-plan moves after its first rule. Self-ruled, Black scored 0.81, against 0.91 with the rule preset; it played 1.0 off-plan moves a game, the ones before its rule.

**Rules on both sides.** With White keeping a RULES.md and Black writing its contract, Black scored 0.56. White still played 4.5 off-plan moves a game; Black played 1.0.

**An empty contract belongs to whoever writes the first rule.** From ply 10, a rogue on each side tried to take over. White's rogue emptied RULES.md 28 times in 16 games; White's agents wrote a new rule after 15 of them. Black's rogue posted a rule that every commit must carry its own signature. Where Black's agents had written their rule first (5 of 16 games), the takeover was refused for lack of signatures, and Black won. In the other 11, `modal` accepted it, and no rule the team wrote after could be accepted without the rogue's signature: Black forfeited all 11. Against the preset contract, the same rogue was refused every time, and Black scored 0.94.

**Pawn personalities change little.** With pawns that differ, Black scored 0.88 against the preset contract (0.91 with uniform pawns), and 0.66 when both sides write rules (0.56 with uniform pawns). The pawns' rates average out to the other agents', and the contract refuses an off-plan move whichever pawn sends it.

## Each experiment

### Both sides over chat {#chat-vs-chat}

*Both sides over chat: no contract, no rules.*

Black scored 0.41: 20 wins, 12 draws and 32 losses in 64 games. Per game, White's agents sent 10.6 off-plan moves and the referee played 8.1; Black's sent 10.4 and 8.2 were played.

### White keeps a RULES.md, Black only chats {#rules-md-vs-chat}

*White writes RULES.md; Black only chats.*

Black scored 0.31: 18 wins, 4 draws and 42 losses in 64 games. Per game, White's agents sent 10.5 off-plan moves and the referee played 4.4; Black's sent 9.5 and 7.0 were played. RULES.md held back 4.6 White off-plan moves a game.

White's agents wrote 172 rules into RULES.md, 2.7 a game; 160 of them cover all three kinds of off-plan move. The first rule of each of the first six games:

| Game | Ply | Author | Rule | Covers |
| ---: | ---: | --- | --- | --- |
| 1 | 21 | pawn_d2 | Only send your piece's move if it is the move the team agreed on in chat for this turn; if your piece is not the chosen piece, stay silent even when a capture looks tempting or your piece is attacked, and if you are the chosen piece, send exactly the agreed move and no other. | panic, greed, amnesia |
| 2 | 7 | knight_b1 | Before sending a move, re-read the team's latest plan in the chat and send only your own piece's move exactly as planned (same piece, same destination square), and only if your piece was named in that plan; if the plan names a different piece, stay silent even when your piece is threatened or could capture something. | panic, greed, amnesia |
| 3 | 5 | pawn_g2 | Before sending a move, an agent must re-read the team's chosen plan in chat and send only its own piece's move if it is named in that plan, matching the exact destination square, and otherwise stay silent, without swapping in a capture or a retreat of its own. | amnesia, greed, panic |
| 4 | 15 | pawn_c2 | Before sending a move, re-read the team's latest agreed plan in chat and send only your own piece's move if you are the piece named in that plan, otherwise stay silent and never send a move that differs from the plan, whether from a threat to your piece, an available capture, or a misremembered plan. | panic, greed, amnesia |
| 5 | 3 | pawn_a2 | Before sending a move, re-read the latest team plan in chat and send only your piece's move if it is the planned move and exactly the planned destination square; if the plan names a different piece, stay silent, and never move because of a threat or an available capture unless the plan says so. | panic, greed, amnesia |

| Formula | Proposed | Accepted | One agent's words |

## What these experiments do not show

- The agents' play is simulated: a shallow shared engine and fault rates.
  Only the rules are written by a language model.
- How often an agent follows RULES.md is a parameter, not something the
  experiments measure. The experiments try 0.5, 0.95 and 1.
- Sixteen games per experiment separate large effects from small ones, not
  close ones.
- A preset contract needs four signatures. Four agents that go off plan
  together get their move accepted.
- Every rule came from one language model, Claude Sonnet 5.5. Another model
  may write other rules; the answers used here are in `results/llm-cache`.

## Reproduce

```bash
cd examples/multi-agent-chess
pip install -r requirements.txt
python3 multi_agent_chess.py experiments --games 16 --jobs 8 --cache results/llm-cache
python3 report.py out/experiments
python3 multi_agent_chess.py play --white rules-md --black self-ruled --rogue --seed 3
```

`results/llm-cache` holds every language-model answer these games used, so
the run above plays the same games without asking a model. Without it,
RULES.md and self-ruled games need one: the Claude Code CLI (`claude`) signed
in, and `modal ai set --provider claude-cli --model claude-sonnet-5-5`. `play` narrates one game and writes a replay page.
