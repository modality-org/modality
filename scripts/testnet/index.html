Modality Network

This is the Foundation-operated public hybrid testnet. It is not mainnet. Anyone may join by mining. Bootstrap nodes are operated by the Foundation until independent pools exist.

Install and join:

curl -fsSL https://get.modality.org/testnet/latest/install.sh | sh
modal node create --dir ./my-node --testnet
modal node run-miner --dir ./my-node --no-tui

Bootstrappers (TCP 4040/ws):

  • node1.testnet.modality.network
  • node2.testnet.modality.network
  • node3.testnet.modality.network

How-to: Join the public testnet. Packages: get.modality.org.
